# Intern_Factory_Dashboard
1. Internship Domain Preference Analysis
By analyzing applications across different internship domains, InternFactory can understand which fields attract the most student interest. This information helps the organization identify popular domains, plan internship opportunities accordingly, and allocate resources to areas with higher demand.
2. College-Wise Application Analysis
Analyzing applications based on college names helps InternFactory identify institutions that contribute the highest number of applicants. The organization can use this information to build stronger relationships with colleges, organize internship awareness programs, and encourage participation from institutions with fewer applications.
3 Business Insights for InternFactory
1. Focus on the most popular internship domains: InternFactory should identify which domains receive the highest number of applications and provide more internship opportunities in those areas. This will help match student interest with available opportunities.

2. Strengthen college partnerships: InternFactory should identify colleges contributing the most applications and build partnerships with them. It can also conduct awareness programs in colleges with fewer applications to attract more students.

3. Encourage students to upload resumes: InternFactory should identify applicants who have not provided resumes and send them reminders to upload one. This will help recruiters evaluate candidates more easily and speed up the selection process.
